Put the images you want to flash in this folder, or in the shared-storage
folder the menu actually reads.

Menu [6] flashes every partition image in the flash folder. Name each file
after the partition: boot.img, vbmeta.img, l_fixnv1.img. A .bin name is
renamed to .img when the flash menu runs. Files the menu ignores: *.txt,
*.xml, SHA256SUMS, *_bak.img, misc-slotinfo.img, misc-before-*.img.

On a phone the folder the menu reads is
    /sdcard/spdhost/input
once termux-setup-storage has been run and allowed -- that is where a browser
download or a file manager copy can reach. This folder is the fallback: when
the phone has not granted storage access, the menu uses the input/ folder
inside the folder the tool was unzipped into. Extra menu [15] shows which one
is in use and switches between them.

Dumps land in backup/ (or /sdcard/spdhost/backup). Menu [9] copies a dump
into the flash folder so a partition you just read off the phone can be the
one you write back, without moving files by hand.

This folder is created by the menu if it is missing. An empty input/ is the
normal state on a fresh copy.
